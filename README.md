# Java Array Programs

This repository contains basic Java programs for learning and practicing array concepts.

## Programs Included

- Sum, Average, Minimum and Maximum
- Binary Search
- Bubble Sort
- Count Odd and Even Numbers
- Forward and Backward Traversal
- Linear Search
- Odd and Even Numbers
- One-Dimensional Array

## Language Used

- Java

## Purpose

These programs are created for practicing basic Java programming and array operations.
